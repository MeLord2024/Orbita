Orbita 是一款免费的 Chromium 浏览器扩展，可在任何网站上添加聊天窗口。无需离开当前页面，即可与其他访问者交流。匿名使用，无需注册。支持按语言划分的聊天室、互动表态、订阅、动态信息流和个性化设置。

## ✨ 主要功能

- 💬 **网页聊天：** 可移动、调整大小和透明度的悬浮聊天窗口。
- 🌍 **8 种界面语言及全球聊天室：** 俄语、英语、德语、法语、西班牙语、意大利语、日语和中文。每种语言都有独立的全球聊天室。
- 🗣️ **54 种聊天室语言：** 可独立于界面语言进行选择。
- 🔗 **按页面划分聊天室：** 根据网址和语言分组，并可合并镜像网站。
- 👤 **匿名参与：** 无需注册，可设置各网站昵称和头像。
- 👍 **社区互动：** 赞成、反对、星标、回复、举报、热门消息和筛选。
- 🔥 **动画效果：** 可拖动的互动特效，使用后充能会恢复。
- 🔔 **通知：** 回复提醒、跳转至消息和活动通知。
- 📌 **订阅：** 收藏感兴趣的讨论。
- 🟢 **实时活动：** 在线人数提示及公开全球聊天室目录。
- 🎨 **个性化：** Frutiger Aero 玻璃风格、主题、背景、渐变和提示音。

## 📱 Android 版 Orbita — v0.3.22

![Orbita Android — 聊天与动态信息流](docs/android-preview.png)

Orbita 也提供独立的 Android 应用。无需浏览器扩展，即可在手机上参与按语言划分的全球聊天室和网站专属讨论。

**主要功能：** 匿名聊天和头像、全球及网站聊天室、8 种界面语言和 54 种聊天室语言、赞成与反对、星标、回复和举报、动态信息流、搜索、筛选及订阅、消息动画效果，以及 Frutiger Aero 和 Blue-Grey 玻璃主题。

**安装方式：** 从 [Releases](https://github.com/MeLord2024/Orbita/releases)下载`Orbita-android-v0.3.22.apk`，在 Android 手机上打开并确认安装。这是测试版本，请仅在信任文件来源时允许安装。

## 🚀 通过 ZIP 安装

1. 前往 [Releases](https://github.com/MeLord2024/Orbita/releases) 下载所需版本的 ZIP。
2. 将 ZIP 解压到固定文件夹。
3. 打开 `chrome://extensions`，开启**开发者模式**，选择**加载已解压的扩展程序**。
4. 选择包含 `manifest.json` 的 `extension` 文件夹。
5. 打开网站并点击 Orbita 扩展图标。

需要 Chromium 114 或更高版本。目前通过 ZIP 文件分发。

## 🔒 隐私

公开聊天室中的消息并非私人通信。可以关闭服务器同步，仅在本地使用。
