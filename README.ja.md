**1つのページに、1つの会話。** Orbitaは、Chromium系ブラウザーでウェブサイトの上に半透明のチャットを表示する無料の拡張機能です。ページを離れずに、同じサイトを見ている人と会話できます。登録は不要です。

## ✨ 主な機能

- 💬 **サイト上のチャット：** ウィンドウの移動、サイズ変更、透明度調整が可能。
- 🌍 **8言語の画面表示とグローバルチャット：** ロシア語、英語、ドイツ語、フランス語、スペイン語、イタリア語、日本語、中国語。言語ごとに専用のグローバルチャットがあります。
- 🗣️ **54のチャット言語：** 画面表示とは別にルームの言語を選択可能。
- 🔗 **ページ別ルーム：** URLと言語ごとに会話を分け、ミラーサイトを統合できます。
- 👤 **匿名で参加：** アカウント登録不要。サイト別のニックネームとアバター。
- 👍 **リアクション：** 投票、スター、返信、通報、人気投稿、フィルター。
- 🔥 **アニメーション：** 回復するチャージを使ったインタラクティブなエフェクト。
- 🔔 **通知：** 返信、メッセージへの移動、アクティビティ通知。
- 📌 **購読：** 気になる会話を保存。
- 🟢 **オンライン状況：** 接続人数の表示と公開グローバルルーム一覧。
- 🎨 **カスタマイズ：** Frutiger Aero、テーマ、背景、グラデーション、通知音。

## 🚀 ZIPからインストール

1. [Releases](https://github.com/MeLord2024/Orbita/releases)からZIPをダウンロードします。
2. ZIPを保存用フォルダーに展開します。
3. `chrome://extensions` を開き、**デベロッパーモード**を有効にして**パッケージ化されていない拡張機能を読み込む**を選びます。
4. `manifest.json` が入っている `extension` フォルダーを選択します。
5. ウェブサイトを開き、Orbitaのアイコンをクリックします。

Chromium 114以降が必要です。現在はZIPで配布しています。

## 🔒 プライバシー

公開チャットのメッセージは非公開ではありません。サーバー同期を無効にしてローカルのみで使用できます。
