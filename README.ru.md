**Одна страница — одна беседа.** Orbita — бесплатное расширение для Chromium-браузеров: полупрозрачный чат поверх практически любого сайта. Общайтесь с другими посетителями страницы, не покидая её. Регистрация не нужна.

## ✨ Возможности Orbita

- **💬 Чат поверх сайтов:** окно можно перемещать, менять размер и прозрачность.
- **🌍 8 языков интерфейса и глобальных чатов:** **русский (Русский), английский (English), немецкий (Deutsch), французский (Français), испанский (Español), итальянский (Italiano), японский (日本語), китайский (中文)**. Для каждого языка предусмотрен отдельный глобальный чат.
- **🗣️ 54 языка комнат:** язык обсуждения можно выбрать отдельно от языка интерфейса.
- **🔗 Чаты по адресу страницы:** комнаты разделяются по URL и языку; зеркала сайтов можно объединять.
- **👤 Анонимное общение:** регистрация не нужна, можно настроить ник для каждого сайта и аватар.
- **👍 Реакции и обсуждения:** лайки, дизлайки, звёзды, ответы, жалобы, топ сообщений и фильтры.
- **🔥 Анимации:** перетаскиваемые эффекты огня, щита и другие реакции с восстанавливающимися зарядами.
- **🔔 Уведомления:** отдельный раздел ответов, переход к сообщению и объединённые уведомления о взаимодействиях в новых сборках.
- **📌 Подписки:** сохранение интересных обсуждений.
- **🟢 Онлайн и активные комнаты:** индикаторы присутствия и каталог публичных глобальных чатов.
- **🎨 Оформление:** стеклянный Frutiger Aero, альтернативные темы, фоны, градиенты и звуки.
- **👑 Администрирование в новых сборках:** режим по «Ключу безопасности», удаление сообщений и очистка комнаты за выбранное количество минут, часов или дней с предпросмотром и подтверждением.

## 🚀 Установка из ZIP

1. Откройте раздел **[Releases — скачать Orbita](https://github.com/MeLord2024/Orbita/releases)** и выберите нужную версию.
2. Распакуйте ZIP в постоянную папку.
3. Откройте `chrome://extensions`, включите **Режим разработчика** и нажмите **Загрузить распакованное расширение**.
4. Выберите папку `extension`, в которой находится `manifest.json`.
5. Откройте любой сайт и нажмите значок Orbita (или настроенное сочетание клавиш).

**Требования:** Chromium 114+. Пока Orbita распространяется ZIP-архивом, а не через Chrome Web Store.

> **Важно о версиях:** опубликованные на GitHub исходники и релиз могут отставать от последней тестируемой сборки. Проверяйте номер версии перед установкой. Не заменяйте работающий Worker более старым серверным кодом из репозитория.

## 🔒 Приватность и безопасность

Сообщения в общих чатах публичные. Синхронизацию можно отключить для локального режима. Административные пароли должны храниться **только в секретах сервера** — их нельзя включать в ZIP расширения или публиковать на GitHub.
